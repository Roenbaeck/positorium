# Positorium 0.3.4-beta.9

Traqula searches and saved constraints can now read individual values from JSON
documents. Use `json_at` to compare or return a field and `json_exists` to
test whether it is present. Both take an RFC 6901 JSON Pointer.

```traqula
search ?record = [{(?order, document)}, ?doc, *]
where json_at(?doc, "/shipping/country") = "SE"
  and json_exists(?doc, "/items/0/quantity")
return ?order, ?record, json_at(?doc, "/items/0/quantity") as ?quantity;
```

A field containing `null` counts as present. A missing field makes a
`json_at` comparison match no row. When returning an optional field, guard it
with `json_exists` as in the example. Extracted numbers compare at full
precision, and returned values preserve their original spelling. For example,
`1.00` compares equal to `1` with `=` and returns as `1.00`.
[Traqula JSON Pointer reference](../reference/TRAQULA.md#json-pointer)

To upgrade an embedded Rust application with on-disk storage, run

```sh
cargo add positorium@=0.3.4-beta.9 --no-default-features --features persistence
```
