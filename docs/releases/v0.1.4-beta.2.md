# Positorium 0.1.4-beta.2

This beta adds an embedded Python distribution and a substantially richer
interactive example while preserving store format 1.0 and Traqula 1.

## Included

- CPython 3.9+ bindings for in-memory and append-only persistent databases,
  multi-search execution, typed parameters, deadlines, row limits, structured
  exceptions, and authoritative Terrain reports
- Lossless Python `Cell`, `Row`, `ResultSet`, and `ExecutionResult` values, plus
  dictionary and optional Pandas conversion helpers
- Stable-ABI wheels for Linux, macOS, and Windows, an installable source
  distribution, and tag-gated PyPI Trusted Publishing
- The Blackthorn Ruby detective case, with 15 narrated searches demonstrating
  provenance, contradictions, retractions, temporal cuts, classifications, and
  Terrain
- A Query Studio action that loads the complete detective case without
  automatically executing or overwriting editor contents without confirmation
- A first-visit Query Studio path with Local WASM enabled, a short preloaded
  conflicting-evidence example, and direct documentation and feedback links
- A typed client error for mutation variables recalled outside their script,
  leaving later HTTP requests healthy

## Compatibility

Python interface 1 is a new additive contract. Store format 1.0, Traqula 1,
HTTP v1, SSE 1, WASM 1, Terrain 1, logical export 1, and identity remap 1 are
unchanged. The PyPI version is normalized from Cargo `0.1.4-beta.2` to PEP 440
`0.1.4b2`.

## Important boundaries

- The Python package embeds the single-process Rust engine; it is not a remote
  client and does not make the unauthenticated HTTP service Internet-safe.
- One process owns a persistent store. Use the `Database` context manager or
  call `close()` before another process opens the same store.
- Result conversion is deliberately lossless by default. Numeric, JSON, and
  temporal text is not silently coerced into Python values.
- Installing an sdist requires Rust. Prefer a published wheel on supported
  platforms.

## Start testing

Before the tag is published, install the source checkout with
`python -m pip install .`. After publication, install with
`python -m pip install --pre positorium`, then follow the [Python
guide](../guides/PYTHON.md). The browser and native archive paths remain
documented in [Getting started](../GETTING_STARTED.md).
