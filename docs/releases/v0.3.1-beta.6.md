# Positorium 0.3.1-beta.6

Positorium is available as an embedded Rust crate. From another Cargo project,
add it with

```sh
cargo add positorium@=0.3.1-beta.6 --no-default-features --features persistence
```

Use `Database::open(path)` for a durable store or `Database::memory()` for
an ephemeral one. Run scripts directly on the database, bind Rust values with
`ExecutionOptions::bind`, and read lossless cells by projected column name.
`execute_one` checks for exactly one projection before applying any writes.
Existing `Engine` and `PersistenceMode` callers continue to work, and existing
format 1.0 stores open directly. [Rust crate](https://crates.io/crates/positorium/0.3.1-beta.6) · [Rust API](https://docs.rs/positorium/0.3.1-beta.6/positorium/)
