# Positorium 0.1.4-beta.3

This milestone makes Traqula's temporal results independent of join order,
introduces typed execution plans and `EXPLAIN`, and replaces pairwise temporal
reduction with a shared interval-aware kernel.

## Included

- Snapshot joins apply external Posit, value, and time bindings after temporal
  reduction, preserving ordinary and latest-matching semantics.
- Exact Thing unions, lexical negation scopes, common typed union schemas,
  dependency validation, invalid limits, and mixed numeric/certainty ordering
  have regression coverage. Invalid compound searches fail before output or
  fallback mutation.
- `explain search ...;`, `Engine::explain`, and `Engine::explain_with_options`
  expose the chosen physical plan without evaluating results or running a
  fallback. Plans show typed bindings, access paths, join order, estimates,
  temporal operations, and result modifiers.
- Ordinary snapshots, latest matching, effective evidence, retractions, and
  Terrain share temporal dominance logic. Reduction preserves every equal or
  incomparable maximum, source-local multiplicity, cancellation, and work limits.
- Forty-five end-to-end benchmarks record before-and-after timings at 128,
  512, and 2,048 rows. At 2,048 rows on the measured M1 Pro host, ordered
  snapshots improved from 68.39 ms to 0.55 ms and effective retractions from
  44.02 ms to 0.49 ms. See the [methodology and full results](../development/BENCHMARKS.md).

## Compatibility

Query plan version 1 is a new additive contract. Store format 1.0, Traqula 1,
HTTP v1, SSE 1, WASM 1, Python 1, Terrain 1, logical export 1, and identity remap
1 retain their versions. The Python distribution version is `0.1.4b3`.

The corrected query behavior rejects negative or overflowing limits, invalid
variable scopes and branch types, and unsupported mixed sort domains that could
previously be accepted or fail only for particular data. Snapshot results no
longer depend on which joined pattern executes first. Effective-evidence work
counters include the interval-start comparisons performed by the new reducer.

## Execution boundaries

This milestone still materializes intermediate query results. Plans label limits
as presentation-only, and `EXPLAIN ANALYZE` is not yet available. Incremental
execution, effective-slice indexing, and operator runtime profiling remain in
the [roadmap](../development/ROADMAP.md).
